# SHAMS: evaluation code and released model outputs

[![Paper](https://img.shields.io/badge/arXiv-2610.01427-b31b1b.svg)](https://arxiv.org/abs/2610.01427)
[![Dataset](https://img.shields.io/badge/%F0%9F%A4%97%20Dataset-shams--nlp%2Fshams-blue)](https://huggingface.co/datasets/shams-nlp/shams)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

This repository contains the evaluation code, the released model outputs, and
the inter-annotator agreement study for the paper
[**SHAMS: An Audio-Grounded Pronunciation Benchmark for Levantine Arabic**](https://arxiv.org/abs/2610.01427)
(ArabicNLP 2026). Every number, table and qualitative example in the paper is
produced by the code here from the files here.

SHAMS is a variety-stratified benchmark for Levantine Arabic. Each of its
1,300 utterances carries four aligned tiers, so four tasks are measured over
the same material:

```
                 ┌─────────────── G2P ───────────────────────────────┐
                 │                                                   ▼
audio  ──ASR──▶  orthographic  ──diacritization──▶  diacritized      phonetic
  │                                                                  ▲
  └──────────────────────────── A2P ─────────────────────────────────┘
```

| Path | What it holds |
|---|---|
| `shams_eval/` | The evaluation package and the `shams-eval` command line |
| `predictions/` | Released model outputs, one file per system per task ([details](predictions/README.md)) |
| `iaa/` | The inter-annotator agreement study ([details](iaa/README.md)) |
| `results/` | The paper's results and LaTeX tables, generated by `make all` |

## Reproducing the paper

Python 3.10 or later.

```bash
git clone https://github.com/bensapirstein/shams.git
cd shams
pip install -e . datasets
make all
```

This scores every released system on all four tasks and runs the agreement
study, in under a minute on a laptop. The tables it writes match the
committed `results/tables/` byte for byte. References are read from the Hub at a pinned
revision; to score offline from a local snapshot, run
`make all DATASET=path/to/shams.jsonl`.

| Paper | File in `results/tables/` |
|---|---|
| Main results per task and variety | `<task>_results_table.tex` |
| System descriptions | `<task>_models_table.tex` |
| Within-variety source contrast | `<task>_source_contrast_*.tex` |
| A2P direct versus cascade | `a2p_cascade_appendix.tex` |
| Qualitative examples | `<task>_qualitative_table.tex`, `appendix_examples.tex`, `multiglossia.tex` |
| Inter-annotator agreement | `iaa.tex` |

## Evaluating your own system

Write one JSON Lines file with one record per utterance:

```json
{"seg_id": "46385_1", "prediction": "هاظا بتسلمو لعمك أبو جبر"}
```

The hypothesis field is `prediction` for `asr`, `prediction_raw` for
`diacritization`, and `prediction_translit` for `g2p` and `a2p`. Then run:

```bash
shams-eval score asr path/to/your-system.jsonl --by-source
```

The gold text and the variety labels always come from the release. Any other
key in your file is reported as provenance and not scored.

## Metrics

WER and CER for ASR, DER for diacritization as the CATT reference
implementation computes it, CER for G2P, and per-utterance-capped CER for A2P.
Scores are reported overall, per variety and per source corpus.

Each tier is scored under two normalizations, applied to reference and
hypothesis alike:

| Tier | Primary | Second |
|---|---|---|
| orthographic | `neutral`: alif / tāʾ marbūṭa / alif maqṣūra fold, diacritics stripped | `strict`: surface-faithful |
| diacritized | `paper`: Appendix B.1, MSA case-tanwin dropped | `tanwin_included`: the paper's ablation |
| phonetic | `neutral`: alphabet mapping + notation fold | `strict`: alphabet mapping only |

## Audio

The dataset on the Hub includes the audio of the 907 LangMedia rows. The 393
Casablanca rows are access-gated upstream, so their audio is fetched from the
source; see the [Casablanca rows](https://huggingface.co/datasets/shams-nlp/shams#casablanca-rows)
section of the dataset card.
